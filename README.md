# Quiz World

Professional quiz platform V1 foundation.

## Included in V1 foundation

- Premium professional homepage
- Separate Explore, Leaderboard, AI Quiz, Login, Student Dashboard, and Join Quiz views
- Student "Attend Quiz by Code" flow foundation
- Responsive blue/white visual system inspired by the existing Pavan Educator design direction
- Featured quizzes, daily challenge, category cards, performance KPI cards, and leaderboard preview
- Frontend structure ready for a real auth/database/quiz backend

## Run locally

1. Install Node.js
2. Run:
   ```bash
   npm install
   npm run dev
   ```

Then open the local Vite URL shown in the terminal.
